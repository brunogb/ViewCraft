# ViewCraft

A SwiftUI component library extracted from KavSoft's examples. Companion to
[ViewCrafter](https://github.com/brunogb/ViewCrafter), the app that showcases
every entry.

## Status

Bootstrapping. This package is currently empty — every component still lives
in `UnpublishedViewCraft`, a local package bundled with the ViewCrafter app,
while it's vetted for public use. Components move here one at a time as
they're ready; nothing here yet means nothing's been promoted yet, not that
something's broken.

## Requirements

iOS 26+, macOS 26+, Swift 6.2+.

## Versioning

Once the first component ships, this package will version by tag (semver).
Until then, depend on it at your own risk — the API can and will change
without notice.

## Installation

```swift
.package(url: "https://github.com/brunogb/ViewCraft.git", from: "0.1.0")
```
